# Исследование Dark Reader

## Решение

NightTime использует локально встроенный Dark Reader 4.9.128 через адаптер `SmartEngine`. Библиотека собирается с WXT и Manifest V3, работает в content script, поддерживает SPA и iframe и полностью удаляет добавленные стили при выключении.

## Ограничения и адаптация

- API-прокси `document.styleSheets` и `customElements` отключены для совместимости со строгими CSP.
- Версионируемый патч `patches/darkreader+4.9.128.patch` предотвращает создание inline-script, когда оба прокси отключены.
- Cross-origin CSS и шрифты загружаются через ограниченный service worker, поскольку обычный fetch из content script подчиняется CORS.
- Изображения и видео не инвертируются отдельным фильтром NightTime.

## Проверки

Автоматический сценарий `tests/e2e/engine-spike.spec.ts` проверяет включение и выключение Dark Reader, отсутствие дублирования стилей, SPA-навигацию, iframe, CSP, профили, overlays, focus-стили и popup. Актуальные числа тестов и размер сборки не фиксируются в документе: источником истины являются вывод `npm run test:all` и свежая `.output/chrome-mv3`.

## Оставшиеся ручные проверки

Перед публикацией необходимо пройти матрицу из `docs/RELEASE_CHECKLIST.md`, особенно видеосервисы, cross-origin iframe, закрытый Shadow DOM, внешние CDN-стили и возможную светлую вспышку при первой загрузке.
