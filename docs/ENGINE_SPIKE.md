# Engine spike: Dark Reader

## Цель

Проверить, можно ли безопасно использовать локальную библиотеку `darkreader` в WXT-расширении Manifest V3 как основу SmartEngine.

## Реализация прототипа

- Content script запускается на HTTP/HTTPS-страницах с `document_start`.
- `ThemeController` хранит локальное состояние и повторно не вызывает Dark Reader для одинаковых настроек.
- Popup содержит одну крупную кнопку включения и два читаемых ползунка: яркость и контраст.
- Настройки сохраняются только в `chrome.storage.local`.
- Dark Reader подключён из `node_modules` и включается в production bundle; CDN и удалённый JavaScript не используются.

## План проверки

1. Собрать production-версию и проверить Manifest V3.
2. Выполнить unit-тесты контроллера и нормализации настроек.
3. Запустить E2E в Chromium с загруженным unpacked-расширением.
4. Проверить вручную светлую страницу, SPA, same-origin iframe, изображения и видео.
5. Зафиксировать размер `.output/chrome-mv3`, ошибки консоли и итоговое решение.

## Результаты

### Сборка и состав Manifest

- `npm run build` завершился успешно.
- Итоговый каталог `.output/chrome-mv3` занимает **313,10 KiB**.
- Сборка содержит Manifest V3, локальные `background.js`, `popup.html` и content script.
- Запрошено только разрешение `storage`; `history`, `cookies`, `webRequest` и другие не требуются.
- В manifest нет удалённых script-адресов. Dark Reader попадает в локальный content bundle из `node_modules`.

### Автоматические проверки

- ESLint: успешно.
- TypeScript strict: успешно.
- Unit-тесты: 4 из 4 успешно.
- Playwright E2E: успешно.

E2E поднимает локальную светлую страницу и загружает production-сборку как unpacked extension. Проверено:

1. SmartEngine включает тему и добавляет Dark Reader styles.
2. Повторная команда с одинаковыми параметрами не дублирует styles.
3. Выключение удаляет все Dark Reader styles без перезагрузки.
4. Content script работает после SPA-навигации в текущем документе.
5. Тема применяется к same-origin iframe.
6. В тестовой fixture не появляется CSS-инверсия для изображения и video-элемента.
7. Popup открывается, содержит одну крупную кнопку и читаемые ползунки яркости и контраста.

### Ограничения текущего прототипа

- Проверка видео относится к video-элементу без реального медиапотока; воспроизведение на видеосервисах ещё не проверялось.
- Не проверены cross-origin iframe, закрытый Shadow DOM, полноценная ручная матрица сайтов и белая вспышка до загрузки настроек.
- Нет FilterEngine, доменных переопределений, расписания, полноценной страницы настроек и локализации. Они не входят в этап 0.

## Решение

**Продолжить с Dark Reader через текущий адаптер.** Библиотека корректно собирается с WXT/MV3, работает в content script и очищает собственные стили. Адаптерный слой `ThemeController` остаётся обязательной границей: popup и будущая фоновая логика не должны импортировать Dark Reader напрямую.

Для совместимости со строгими CSP отключены API-прокси `document.styleSheets` и `customElements`. Dark Reader 4.9.128 создаёт inline-script даже при выключенных прокси, поэтому применяется локальный воспроизводимый патч `patches/darkreader+4.9.128.patch`: script не создаётся, когда оба прокси отключены. Динамическая обработка DOM и обычных style/link-элементов сохраняется; сайты, зависящие от программного изменения CSSOM, могут потребовать отдельное исправление.
