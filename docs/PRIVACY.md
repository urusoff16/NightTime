# Privacy disclosure / Конфиденциальность

## Русский

NightTime не собирает, не продаёт и не передаёт персональные данные. Расширение не использует аналитику, рекламу, внешние серверы или удалённый JavaScript.

Настройки пользователя хранятся локально через `chrome.storage.local`. Доступ к HTTP/HTTPS-страницам необходим только для применения тёмной темы и получения связанных таблиц стилей. Внешние CSS и шрифты загружаются непосредственно с адресов, указанных посещаемой страницей; ответы не сохраняются на сервере разработчика и не отправляются третьим лицам от имени NightTime.

NightTime не читает пароли, историю браузера, cookies, содержимое буфера обмена или данные форм с целью хранения или передачи.

## English

NightTime does not collect, sell, or transmit personal data. The extension contains no analytics, advertising, external application server, or remotely hosted JavaScript.

User preferences are stored locally with `chrome.storage.local`. Access to HTTP and HTTPS pages is used only to apply the dark theme and retrieve stylesheets referenced by the visited page. Remote CSS and font responses are not stored on a developer-operated server and are not forwarded to third parties by NightTime.

NightTime does not read passwords, browser history, cookies, clipboard contents, or form data for storage or transmission.
