# Changelog

## 0.1.7 — Smart Dark color analysis

- В отчёт Smart Dark добавлены начальные OKLab-кластеры цветов текста и достоверных поверхностей.
- Кластеры сохраняют площадь выборки и семантические роли без хранения DOM или текста страницы.

## 0.1.6 — Conservative page classification

- Градиенты, фоновые изображения и полупрозрачные образцы больше не искажают классификацию страницы цветом подложки.
- Добавлены проверки неопределённых, светлых и тёмных выборок.

## 0.1.5 — Smart Dark Shadow DOM fixes

- Исправлен инкрементальный обход новых host-элементов с открытым Shadow DOM.
- При удалении host коррекции текста внутри Shadow DOM снимаются с восстановлением исходного цвета.
- Добавлена E2E-проверка сканирования и очистки Shadow DOM.

## 0.1.4 — Smart Dark readability core (in progress)

- Добавлено локальное вычисление контраста текста с попыткой минимальной OKLCH-коррекции после базовой темы.
- Начаты ограниченный сбор видимых текстовых стилей, расчёт фона по предкам и пакетная обработка динамических изменений.
- Добавлены восстановление маркеров/стилей и повторное применение от свежих настроек профиля.
- Полный план Smart Dark остаётся поэтапным: CSS variables, кластеризация, уровни вмешательства, градиенты и debug inspector ещё впереди.

## 0.1.3 — Chat composer and image resource fixes

- Removed NightTime focus decoration from rich text editors such as the ChatGPT composer.
- Allowed bounded public image resources required by dynamic Dark Reader themes.

## 0.1.2 — Remote resource messaging fix

- Fixed external stylesheet requests when embedded Dark Reader wraps `chrome.runtime.sendMessage`.
- Added a guarded callback transport for background responses.

## 0.1.1 — Focus and profile fixes

- Removed the inner focus frame from Google-style combobox fields.
- Reset the complete color palette when switching visual profiles.
- Added the installed extension version to the popup header.

## 0.1.0 — Beta

- Добавлены профили «Лунный индиго» и «Тёмный изумруд» с отдельными палитрами.
- Индивидуальный режим сайта получил состояния «по общим правилам», «всегда включать» и «всегда выключать»; конкретные поддомены имеют приоритет.
- Ненадёжное распознавание нативной тёмной темы отключено по умолчанию с миграцией настроек на схему 2.
- Затемнение и Night Shift больше не накладываются повторно внутри iframe.
- Синяя линия фокуса полей заменена на почти чёрную, а для клавиатурной навигации сохранена отдельная нейтральная рамка.
- Удалены неработающие параметры `saturation`, `invertImages` и `linkColor`; остальные цвета профилей подключены к слою читаемости.
- Язык документа синхронизируется с выбранным языком интерфейса.
- Внешние CSS и шрифты Dark Reader загружаются через ограниченный service worker: локальные сети, опасные типы и ответы больше 2 МБ блокируются.
- Минутный опрос в каждом iframe заменён одним общим `chrome.alarms` для активного расписания.
- Добавлены фирменные иконки 16/32/48/128 px, privacy disclosure и актуальная документация beta-версии.
- Тема применяется к связанным `about:blank`, `data:` и `blob:`-фреймам с наследованием домена родительской страницы.

## 0.0.1 — Engine spike

- Добавлен WXT-проект с Manifest V3, service worker и content script.
- Dark Reader подключён локально через `ThemeController`.
- Добавлен компактный popup: одна главная кнопка, яркость и контраст.
- Добавлены unit- и Playwright E2E-тесты для жизненного цикла движка.
- Результаты исследования зафиксированы в `docs/ENGINE_SPIKE.md`.
- Добавлены стартовая страница настроек и базовые локали Chrome для русского и английского языков.
- Добавлена версионируемая модель настроек, нормализация импорта, миграция прототипа и resolver приоритетов для сайтов и расписания.
- Content script применяет effective settings из локального хранилища.
- Добавлены FilterEngine, SmartEngine-адаптер и безопасный менеджер переключения движков с fallback.
- Добавлен слой читаемости, отделяющий поля ввода и формы от тёмного фона.
- Отключены прокси Dark Reader и добавлен воспроизводимый патч, исключающий inline-script на сайтах со строгой CSP.
- Добавлены готовые профили «Тихая ночь», «Полярная тень», «Тёплый вечер», «Чёткий фокус» и «Бездна», а также реальное затемнение страниц.
- Удалён «Быстрый» режим: старые настройки автоматически переходят на «Умный» режим.
